# Gajanan Tayde Portfolio

Static responsive personal portfolio.

## Deploy with Vercel
1. Import `Gajanan108/Gajanan108` into Vercel.
2. Set **Root Directory** to `portfolio`.
3. Select **Other** as Framework Preset.
4. Leave Build Command blank and set Output Directory to `.`.
5. Deploy.
